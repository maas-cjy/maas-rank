「限时免费」= 官方标注限时免费，恢复收费请以官网现价为准；「—」= 未收录到官方定价（不代表免费，可能是未公开报价或需按量询价）。 海外模型按美元报价显示，排序按 $1≈¥7.2 折算。DeepSeek 等分时计价模型取高峰刊例价，空闲时段与缓存细则见成本计算或模型详情页。

字段口径说明

  • 输入 / 输出单价：每百万 tokens 的 API 报价。国产模型为官方人民币报价；海外模型显示官方美元价，括注按 $1≈¥7.2 折算的人民币参考值。
  • 缓存命中：读取已有缓存内容时的输入 token 单价，通常远低于未命中价。缓存命中 ≠ 缓存存储——前者是「读」的折扣价，后者是缓存保存成本（部分厂商按存储时长另计）。当前仅官网直采模型有此字段。
  • 价格核验：每行单独标注该模型价格的核验时间。不同模型日期可能不同——多数来自 SuperCLUE 2026年7月 价格表，官网直采模型为当日核验。
  • 来源：「官网」表示直采自厂商官方定价页（高峰/分时、分段定价、缓存细则等完整规则见各模型详情页）；「价格表」表示来自 SuperCLUE 价格库。
  • 完整计价规则（高峰/空闲、分段档位、多模态）不在本表抹平展示，请进入模型详情页查看「价格来源」与价格说明。
